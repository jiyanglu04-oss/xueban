# 学伴 · 大学生课程 / 待办 / 通知聚合工具

把「课表 + 待办 + 各学习平台消息 + 四六级备考」装在一起的小工具。
**全部数据都存在你自己电脑上，不上传任何服务器，也不需要注册账号。**

> 一个本地跑的桌面小工具，帮你把散落在超星学习通、雨课堂、中国大学 MOOC 上的
> 课程、通知、作业收拢到同一个页面。不用再在五个 App 之间反复横跳。

---

## 下载

1. 点右上角绿色的 **Code → Download ZIP**（或者去 [Releases](../../releases) 下载打包好的版本）
2. 解压到任意一个普通文件夹（**别放 C 盘根目录**，也**别放在中文路径特别深的目录**）
3. 双击 **`启动工作台.bat`** —— 后面的事看下面的「三步开始」

**系统要求**：Windows 10 / 11（64 位）。
不需要预装 Python，不需要管理员权限，不需要注册任何账号。

---

## 三步开始

**1. 解压**

把压缩包解压到一个普通文件夹里就行（别放在 C 盘根目录）。

**2. 双击 `启动工作台.bat`**

第一次运行会自动准备运行环境：下载一个精简版 Python 和抓取组件，约 50 MB。
视网速需要 2~5 分钟。**这一步只做一次**，以后每次启动都是秒开。

> 你不需要事先装 Python，也不用改任何系统设置，更不需要管理员权限。
> 所有东西都装在文件夹里的 `runtime\` 下 —— 删掉文件夹就等于卸载干净。

**3. 跟着页面上的向导走**

浏览器会自动打开，页面上弹出「首次设置向导」：

| 步骤 | 你要做的 |
| --- | --- |
| ① 说明 | 看一眼，点右下角「开始设置 →」 |
| ② 课表 | 设置开学日期和学期周数，上传课表图片；本机识别后确认课程，也可以先跳过 |
| ③ 登录平台 | 点卡片上的「扫码登录」，用手机扫码（超星 / 雨课堂 / MOOC，用哪个登哪个；暂时用不上的点「都先跳过」，以后随时能补） |
| ④ 抓数据 | 点右下角「登录好了，开始抓数据 →」，等 20~40 秒，全程自动 |
| ⑤ 完成 | 点「进入工作台 →」，你的课程和通知已经在里面了 |

抓取借用的是你电脑上已经装好的 **Edge 或 Chrome**，不需要另外下载浏览器。

**课表图片导入：** 向导和「我的课表 → 导入课表图片」均可上传清晰的整周课表。
保留星期列与左侧节次栏，识别后核对课程名、教室、节次、起止周和单双周，再确认追加。
识别不确定的值会使用默认值，不能省略校对；不会删除已有课程。也可以手动补录。
开学日期按所在周的周一作为第 1 周，之后可在「设置」修改。
图片只在本机处理，不需要 AI 账号。Windows 需要安装中文「光学字符识别」语言功能；
Python 识别组件由首次运行自动准备，旧运行环境缺组件时会补装。

想更省事：双击 **`创建桌面快捷方式.bat`**，桌面会多出一个「学伴」图标。

## 有什么功能

| 视图 | 干什么 |
| --- | --- |
| 总览 | 今天要上什么课、有哪些待办到期、各平台未读数 |
| 我的课表 | 上传课表图片，识别并校对；用起止周输入框与单双周下拉框调整排课，支持临时调课 |
| 待办 | 从各处搜集的要动手的事，可按截止时间排 |
| 消息中心 | 各平台的完整通知流水，可搜索、可一键「转待办」 |
| 课程管理 | 本学期的课（可一键切换查看全部） |
| 备考与考试 | 四六级打卡与倒计时；添加多门期末考试日期、地点和独立倒计时 |
| 平台连接 | 各个学习平台的登录状态 |
| 设置 | 学期日期、作息时间、数据备份 |

快捷键：`/` 搜索，数字键 `1`~`8` 切换视图，`N` 新建待办。

## 让消息自己进来

首次向导里登录过一次之后：

- 双击 **`一键同步数据.bat`** 手动抓一次；
- 双击 **`注册自动同步.bat`** 让它每天 08:00 / 20:00 自动抓（电脑关机错过会补跑）。

登录态有有效期（一般一到两周），过期后界面上会有提醒，
点「设置 → 查看同步方法 → 重看设置向导」，或者双击 `重新登录.bat` 再扫一次码即可。

> **它只看得到「平台通知里写了的」东西。** 微信群聊、QQ 群消息抓不到 ——
> 这部分需要按 `sync/import_notices.py` 里的说明手工录入。
> 教务系统同样不在自动抓取范围内，课表请直接录入。

## 想要每日提醒

双击 **`注册每日提醒.bat`**，之后每天 08:00 和 20:30 会在电脑上弹一条整合通知
（今天要做什么 / 明天要做什么）。不想用了就双击 **`取消每日提醒.bat`**，
想立刻看一条效果就双击 **`立刻提醒我.bat`**。

## 数据在哪

全部在 `data/workbench.sqlite3` 这一个文件里。**想备份就复制它。**

它永远在你自己电脑上，这个工具不会把你的课表、成绩、通知发到任何服务器。

## 目录说明

```
学伴/
├─ 启动工作台.bat          ← 平时双击这个（第一次会自动装好环境）
├─ setup_runtime.ps1       ← 上面那个脚本调用的环境准备逻辑
├─ 创建桌面快捷方式.bat    ← 在桌面生成「学伴」图标
├─ 一键同步数据.bat        ← 手动抓一次平台数据
├─ 注册自动同步.bat        ← 每天自动抓
├─ 注册每日提醒.bat        ← 每天弹通知
├─ 重新登录.bat            ← 登录态过期时用
├─ 安装环境.bat            ← 环境装坏了时用来重建
├─ 学伴.html               ← 离线单文件版，不启动服务也能用（数据存在浏览器里）
├─ 使用说明.md             ← 更详细的说明
├─ Design.md               ← 界面设计规范
├─ backend/                ← 本地服务（Python 标准库，无需额外框架）
├─ src/                    ← 前端源码（改完要跑 build.py 重新生成单文件）
├─ sync/                   ← 各平台抓取适配器 + 通知导入 + 每日提醒
├─ tests/                  ← 单元测试：python -m unittest discover -s tests -t .
├─ assets/                 ← 图标
├─ runtime/                ← 第一次启动时自动装在这里（可以整个删掉重来）
└─ weapp/                  ← 微信小程序版（需要自己注册 AppID，见 weapp/配置指引.md）
```

## 常见问题

**双击 `启动工作台.bat` 后窗口里在下载东西，正常吗？**
正常。那是第一次在准备运行环境（约 50 MB）。下载完就会自动打开页面。

**卡在「正在下载运行环境」很久，或者提示下载失败？**
换个网络再双击一次。脚本内置了国内镜像，会自动换源重试；已经下好的部分不会白费。

**浏览器提示「无法访问此网站」？**
服务还没起来，等几秒刷新。也要确认启动时那个黑窗口还开着 —— 关掉它服务就停了。

**课表里的课对不上？**
去「设置」检查「学期第一周的周一」是不是填对了 —— 单双周全靠这个日期推算。

**抓不到数据 / 提示要登录？**
登录态过期了，双击 `重新登录.bat` 重新扫码。

**想彻底删掉它？**
直接删掉整个文件夹就行，它没有往系统里装任何东西。

## 这个工具不做什么

- 不保存你的校园账号密码（登录一律靠你自己扫码）；
- 不抓教务系统、不读微信群完整聊天记录；
- 不把你的任何数据传到服务器上。

**它是本地工具，不是「代刷 / 查成绩」类服务。**
